# dev-learning-hub

A beginner-friendly full-stack starter project featuring a simple task manager.

## Project Structure

- `backend/` - Node.js API server
- `public/` - Frontend UI (HTML, CSS, JavaScript)
- `test/` - Node test files for backend behavior

## Run Locally

```bash
npm install
npm test
npm start
```

Open `http://localhost:3000` to use the app.

## Starter Features

- Task CRUD API (`/api/tasks`)
- Clean UI with reusable task item component
- In-memory data store for easy understanding and extension
